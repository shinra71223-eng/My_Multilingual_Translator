# 🌐 同時多言語翻訳アプリ (Simultaneous Translator) - ユーザーガイド

このアプリは、日本語、英語、簡体中国語、繁体中国語（台湾華語）、韓国語を相互かつ同時に翻訳する高機能なシングルページWebアプリケーションです。

---

## 🚀 はじめる前の準備

1. **アプリを開く**
   - 本番環境URL：[https://05-trilingual-traslator.vercel.app](https://05-trilingual-traslator.vercel.app)
   - またはローカル環境の `index.html` をブラウザで開きます。

2. **APIキーを設定する (⚙️ アイコン)**
   - 画面右上にある **⚙️（歯車アイコン）** をクリックして設定画面を開きます。
   - 利用したいエンジンに応じてAPIキーを設定してください：
     - **Gemini AI**: Google AI Studioから取得したAPIキーを入力します。
     - **DeepL Translator**: DeepL Developer Portalから取得したAPIキー（無料版の `:fx` キーまたは有料版キー）を入力します。
     - **MyMemory**: APIキー不要でそのまま即座に利用可能です（接続確認不要）。
   - キーを入力すると自動的にクレンジング（不要な全角スペースや改行の自動除去）が行われます。
   - **「Test」ボタン** をクリックして、緑色の `🟢 Connection Success!` が表示されれば接続完了です。

---

## 💡 主要機能の使い方

### 1. 同時翻訳の実行
- **テキスト入力 (タイピング)**
  - 翻訳したい言語のカードをクリックすると、そのカードが **青い太枠（アクティブ状態）** になります。
  - キーボードで文章を入力し、Enterキーを押すかフォーカスを外すと、他の4つの言語へ同時に翻訳が実行されます。
- **音声入力 (音声聞き取り)**
  - アクティブ状態のカード内にある **🎙️（マイクアイコン）** をクリックするか、画面下部中央の青い **「🎙️ SPEAK」ボタン** をクリックします。
  - 音声の聞き取りが開始され、話し終わると自動的にテキストに変換され、同時翻訳が実行されます。
- **音声読み上げ (再生)**
  - 各言語カードの右側にある **🔊（スピーカーアイコン）** をクリックすると、その言語のネイティブ音声で翻訳結果を読み上げます。

### 2. 📍 ローカル旅行アシスタント (Local Travel Assistant)
画面右上にある **📍（ピンアイコン）** をクリックすると、旅行者向けのアシスタント画面が開きます。

- **現在地の設定 (Where are you now?)**
  - 「Taiwan 🇹🇼」「Japan 🇯🇵」「United States 🇺🇸」「China 🇨🇳」「South Korea 🇰🇷」から現在滞在している場所を選択します。
- **定番プリセットフレーズ (Travel Presets)**
  - シチュエーションごとに厳選された現地の必須表現リストが表示されます。
  - **🔊 アイコン**: フレーズの音声読み上げを行います。
  - **✏️ アイコン**: フレーズをメイン画面の入力欄にコピーし、他言語への同時翻訳を実行します。
- **AI現地表現アドバイザー (Local Expression Advisor) ⚠️ Gemini接続時のみON**
  - メイン画面に入力・翻訳されたテキストがある状態でこのアシスタントを開くと、**「Ask Gemini for Local Native Phrase」** ボタンが有効になります。
  - このボタンをクリックすると、Gemini AIが現在の滞在先に合わせて、**現地の人々が日常会話で実際に使う最も自然なスラング、俗語、地域特有の表現（例: 台湾での地下鉄を「地鐵」ではなく「捷運」にするなど）** にニュアンスを自動的に書き換えて提案してくれます。

### 3. ステータスインジケーター & デバッグログ (設定画面内)
- **ステータスシグナル (画面最下部)**
  - **STT (音声入力)**、**Translation AI (翻訳エンジン)**、**TTS (音声読み上げ)** の状態がカラーシグナルで常時表示されます。
    - `🟢 緑`: 準備完了 / 接続成功
    - `🟡 黄`: キー未設定
    - `🔴 赤`: 接続エラー
- **デバッグログパネル (設定画面内下部)**
  - 設定画面の下部には、APIの接続状況、自動検出されたGeminiの最新モデル名、通信エラーのスタックなど、システムの動作状況が高コントラスト（白背景・黒文字）でリアルタイム表示されます。トラブルシューティングにご活用ください。

## 🛠️ トラブルシューティング

- **DeepLでエラーが出る場合**
  - APIキーが正しいか確認してください（無料版プランの場合は末尾が `:fx` になっている必要があります）。
  - キーの入力後、「Test」ボタンを押してステータスを確認してください。
- **音声入力が動かない場合**
  - ブラウザのマイク使用許可が「許可」になっているか確認してください。
  - SafariやChromeなど、Web Speech API (SpeechRecognition) に対応したモダンブラウザをご利用ください。
- **古い機能や古いバージョンが表示される場合**
  - ブラウザのキャッシュが原因です。`Ctrl` + `F5`（強力な再読み込み）を行うか、シークレットウィンドウでお試しください。
